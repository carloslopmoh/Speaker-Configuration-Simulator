# Speaker Configuration Simulator

> An interactive simulation tool developed in MATLAB, designed to calculate and visualize the optimal speaker setup in various rooms and environments.

## Description

**Speaker Configuration Simulator** is a project aimed at sound engineers, audiophiles, and home theater enthusiasts. It allows you to simulate different speaker arrangements (such as 2.0, 5.1, 7.1, or custom setups) based on room dimensions, helping you find the acoustic "sweet spot" and optimize your listening environment.

## Key Features

* **Positioning Calculation:** Calculates ideal distances and angles based on industry standards.

* **Visual Interface:** Graphical representation of the listening space and the speaker monitors.

* **Multi-format Support:** From classic stereo configurations to complex surround sound systems.

* **Native MATLAB implementation:** Easy to run and modify for researchers and students.

## Technologies Used

* **Environment / Language:** MATLAB
* **UI Framework:** MATLAB App Designer
* **Validation Tool:** **Submap** (Global Audio Solutions) - Used to verify and cross-check the accuracy of the acoustic simulations.

## Installation and Usage

Follow these steps to run the simulator on your local machine.

### Prerequisites

* MATLAB (Version R2025a or higher recommended)

* Git (Optional, to clone the repository)

### Steps to Run

1. Clone this repository to your local machine:

   ```
   git clone https://github.com/carloslopmoh/Speaker-Configuration-Simulator.git
   
   ```

   *(Alternatively, you can download the project as a ZIP file and extract it).*

2. Open **MATLAB**.

3. In the MATLAB environment, navigate to the folder where you cloned or extracted the project.

4. Run the main script or application file by typing its name in the Command Window, or by double-clicking it.

## How to Use

1. Launch the application in MATLAB (software_eng.mlapp).

2. Input the dimensions of your room (Width x Length).

3. Select your desired speaker system type (Line Array or Subwoofers).

4. Adjust the listening position to see how the optimal monitor angles and distances are automatically calculated.
